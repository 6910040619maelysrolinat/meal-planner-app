# Frontend

React + Vite interface for Meal Planner.

## Run locally

From this folder, run `npm.cmd install` and `npm.cmd run dev`. The Vite development server normally opens at `http://localhost:5173` and calls the local API at `http://localhost:5000/api`.

The interface includes account registration/login, SQL entity management, recipe/ingredient associations, MongoDB document management and activity logs.
